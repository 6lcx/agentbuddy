## 实现

- 提供方与模型创建、修订更新、启用/禁用、默认模型选择及对应设置页。
- 密钥单独存储，响应不回显；验证错误不回传原始表单输入。修改配置使已有探测结果失效，旧任务仍引用旧配置/凭证。
- Qwen 原生文本 Generation、DeepSeek Chat Completions、Claude Messages；分别编码消息、工具、认证头并解析 SSE。禁止隐式重试；超时、HTTP 错误、限流、截断、提前断流、空响应、坏工具参数不能当成功。
- AgentScope 2.0.11 内置 DashScope 走兼容接口。实际实现使用 ChatModelBase 扩展原生 HTTP 协议，复用框架 formatter 和执行循环；没有另建 Agent 推理循环。
- 后台 Operation 运行文本→工具请求→本地无副作用 echo→工具结果→最终回答探测；结果绑定模型和提供方修订。仅探测通过的配置可以用于新对话。
- 原生文本/工具是本阶段兼容范围；vision 明确为 false，探测仅接受 text+tools，不静默忽略视觉请求。
- OpenAPI 响应契约导出并生成 TypeScript 类型，前端模型/对话响应直接引用。openapi-typescript 要求 TS 5.x，因此锁定 TypeScript 5.9.3，未保留不满足 peer 范围的 TS 7。
