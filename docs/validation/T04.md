## 实现

- 0002_chat 增加模型目录、项目、Run、消息、幂等键、独立 run_events 表；迁移保留 T02 Operation 和事件。
- 首次 POST /runs 原子创建项目、用户消息、运行快照与排队事件。同 key/同请求返回原标识，不同请求冲突；同一项目最多一个非终态运行。
- Worker 使用独立 Operation 槽及两个 Run 槽，模型调用不占 HTTP 请求生命周期；同项目串行，不同项目可并行。停止/重启将未完成 Run 标 interrupted，拒绝晚到结果，不自动重放。
- 真正通过 AgentScope Agent.reply_stream 执行通用文本助手，当前空 Toolkit。文本增量按时间/大小聚合入 SQLite，终态与完整回答原子提交。
- SSE 支持 after 和 Last-Event-ID 补读，客户端按 ID 去重；浏览器断线不影响 Worker。终态前排空已提交事件，刷新可读取历史消息和运行状态。
- 前端保留草稿与待提交幂等键，失败不丢输入；可用模型缺失时引导设置；新增/历史对话、两轮上下文、错误和部分结果展示。
- 上下文超限返回明确失败，历史仍保留。纯问答不创建文件版本；当前无 Skills/MCP/多专家或文件执行能力。
