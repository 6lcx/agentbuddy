# AgentBuddy v0.1.0

把想法交给 AI，把项目文件带回来。这一版以可自行部署的源码形式发布：在自己的电脑或服务器启动，用自己的模型账号完成任务，无需购买域名或使用作者提供的模型额度。

## 可以用它做什么

- 直接对话，或选择专家并组合 Skills、MCP 连接器；当前对话的临时选择不改写专家模板。
- 按需启用自动协作，由主专家拆分任务、安排子专家并汇总项目文件。
- 上传资料，生成文档、表格、演示文稿和通用文件项目；继续对话修改并下载历史版本。
- 查看执行记录、模型用量和工具结果；在支持的安全边界恢复中断任务。

## 自己部署，自己配置模型

安装 Python 3.12、uv、Node.js 24 LTS、pnpm 10.15.1 后，在源码目录执行：

```text
uv sync --project backend --locked
pnpm --dir frontend install --frozen-lockfile
uv run --project backend python scripts/start_local.py
```

打开工作台后，在“设置模型连接”中填写自己的服务地址、API Key 和模型名，运行探测并设为默认模型。源码不包含作者的 API Key、数据库、聊天记录或项目文件。首次安装会生成自己的本地数据目录。

本地启动入口管理 API、Worker 和 Vite 三个进程；服务器常驻部署沿用仓库中的 Linux/systemd/Nginx 方案。办公文件渲染需要额外安装 LibreOffice 和相应字体。

## 本轮实测

真实 DeepSeek 模型运行四类轻量任务各三次，共 12 次任务；回答和交付文件全部通过内容断言。43 次模型调用、27 次工具调用无异常，任务 P50 为 2.474 秒、P95 为 7.919 秒，输入 Token 缓存读取占比为 85.18%。这些是串行小样本基线，完整口径见 `docs/validation/agent-metrics-baseline.md`。
