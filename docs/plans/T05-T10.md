## 接口细化

所有路径都挂在统一 API_PREFIX 下。以下为已实现接口，替代主计划中同一职责的草案命名；OpenAPI 由 scripts/export_api.py 导出。

- GET/POST /capabilities/{skill|expert|connector}：目录和带 revision 的配置保存。
- POST /capabilities/resolve/selection：专家默认项，加手动添加、减手动移除；移除优先。
- POST /skills/import：导入新包或给 skill_id 上传新版本；202 Operation。GET /skills/{id}/versions、POST /skills/{id}/select-version 管理历史包。
- POST /connectors/import：导入包含 mcp.json 与 Python entry 的 ZIP；不启动程序。POST /connectors/{id}/test：由 Worker 真实连接并发现工具。
- POST /uploads：name、draft_id、content_base64；202 Operation，Worker 解包并检查。传输选择 JSON base64 以复用客户端；原始大小限制仍为 50 MiB，编码约增加三分之一体积。Skill/MCP 包限制 20 MiB。
- GET /operations/{id}：等待上传、包解析、连接测试结果。失败保留前端输入并显示错误；提交 Run 只能引用已完成的上传。
- POST /runs：在原字段外支持 calls_limit、seconds_limit、selection、upload_ids、draft_id；能力和模型快照在提交事务中冻结。
- GET/PATCH /projects/{id}/selection：持久化下一轮覆盖；不修改正在执行的 Run。
- GET /runs/{id}/control、POST /runs/{id}/cancel、POST /runs/{id}/interactions/{id}：查看预算、取消、批准/拒绝/回答澄清。确认 digest 绑定具体内容。
- GET /runs/{id}/activity、/runs/{id}/files、/runs/{id}/files/download：执行记录和停止任务的部分产物；部分产物不冒充成功版本。
- GET /projects/{id}/files、/files/{id}/download、/files/{id}/validation：输入/版本、完整 ZIP、结构校验报告与路径增删改。
- GET /runs/{id}/logs/{name}：脚本完整限额日志。工具结果摘要最多 16 KiB，日志最多 1 MiB。

配置当前存储为带类型的 JSON 记录，关系引用在解析/执行时验证；没有引入 Redis、沙箱或工作流编辑器。MCP 锁定 SDK 2.3.0，HTTP 客户端使用其 httpx2 接口；原生模型保持 httpx 适配。

## 状态与发布选择

运行等待期间底层 Run 保持 running，从而继续受同项目唯一活动索引保护；interactions 的 pending 状态映射为公开 waiting_input。取消底层保存 failed + cancelled 错误码，公开映射为 cancelled。活动时长在等待时暂停、回答后恢复，终态结算。当前单专家工具串行，T11 需要扩展到子任务活动计时，不能直接把本轮单专家等待计时用于并行专家。

模型请求最多 180 秒，实际请求和重试均领取共享额度。瞬时模型失败至多重试两次；已输出的流不自动重播。工具默认 120 秒并受余时约束；取消会终止脚本进程树。MCP 连接不可用时仅该必需调用进入补依赖等待；无关连接器不预先连接。外部写结果未知时禁止同轮重放，并阻止把该轮标为完整成功。

版本采用“复制到唯一 staging → 校验 hash/结构 → 原子改名 → 同一个 SQLite 事务提交版本、成功状态和最终消息”。这是对主计划 preparing 行方案的细化：没有另建 preparing 业务行，只有提交事务中的版本才对外可见。进程在提交前中断时，旧版本保持有效，新目录为不可见残留，任务按既有 Worker 恢复规则标 interrupted，不擅自完成或重放外部步骤。残留快照不会被当成最新版；不自动删除历史版本。

文件检查覆盖路径、链接、hash、JSON/CSV 解析、Python 语法；不等同于任意项目业务测试。仅上传而未修改文件的问答不产生新版本。Office 成品需要 T12–T14 验证器，当前不会把缺少 Office 验证的文件标为已验证交付。
