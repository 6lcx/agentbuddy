# T18 对话界面与能力选择重设计

依据用户提供的 WorkBuddy 截图：固定侧栏、宽松的内容区、输入框内的能力标签、点击召唤专家、能力目录与聊天分离。使用这些交互原则，不声称了解其内部实现。

- 默认工作台进入新对话；固定左侧导航及精简历史标题。
- 专家与执行模式合并成一个选择入口：通用助手、自动协作、具体专家。
- Skills/连接器只有一个勾选状态，不再要求用户维护添加和移除两张列表；仍通过既有 overrides API 保存，关闭优先，切换专家保留手动选择。
- 输入区仅呈现附件、专家、能力、模型、发送；预算放高级设置。能力改动仅作用下一轮，运行中的能力快照不变。
- 消息、交付文件、确认和失败状态保持可访问；运行日志默认折叠。移动窄屏可用。
- 校验：前端类型/构建、状态选择回归，浏览器实看新对话、能力开关、专家切换、历史交付及窄屏布局。不为样式改动重跑付费业务矩阵。
