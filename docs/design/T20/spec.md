# T20 设计探索

2026-11-11。用户要求按 huashu-design 优化已有 React 前端。

交付：六候选缩略图、三个可点击 HTML 初稿，统一桌面 1440×900、移动 375×812。确认后才集成生产 React，当前业务实现不替换。

真实内容来自本项目：通用助手、开发/文档/表格/演示/资料整理专家，Office/开发技能，DeepSeek 模型设置入口，项目历史、附件、预算、外部操作确认规则。

参考：用户提供的七张 WorkBuddy 图；已有 React App、Chat、CapabilityCatalog、SessionControls 与 style.css。前端精确基线：主色 #1689f5、侧栏 #eaf4fc、文字 #243b53、侧栏 248px、卡片 20px、输入框 22px。改善正文对比、标签最小12px、正文14–16px、控件至少44px；减少渐变、模板文案、大面积装饰块。

默认用户已有足够明确的偏好，不重复问需求。原型中的历史条目为示例，不连接真实 API、不发送任务。模型/工作空间/专家/技能选择只作用于预览。

素材：复用自有 AgentBuddy 名称，线性工具图标与彩色角色标识，不复制 WorkBuddy logo、头像与品牌素材。人物肖像不是本轮新增素材；正式头像选型在定稿接入时沿用或替换现有自有资产。
