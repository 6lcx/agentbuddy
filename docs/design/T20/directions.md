# 六个候选

用户指定 WorkBuddy 语境，所有方案保持轻量中文任务工作台。参考以提供的真实截图为准；不新增未经核实的竞品事实。风格样张尚未下载，本轮不声称完成随机样张抽取，使用上下文驱动的六个候选替代。

1. A 轻盈对话台（完整）：现实参照为用户 WorkBuddy 对话截图。浅蓝窄侧栏、居中输入、单行任务捷径，默认不展示能力清单。主角是实际任务输入；蓝色集中用于发送和选中态。推荐。
2. B 分栏工作台（完整）：产品工具设计逻辑。左边稳定的任务输入区，右边常驻专家建议；白底、细线与蓝绿少量点缀。内容的“委派给谁”形成双栏骨架。
3. C 极简项目桌面（完整）：项目文件优先的产品设计逻辑。顶部导航、左侧项目引导与最近项目、右侧输入面板；以项目续作形成横向工作桌。与 A/B 的侧栏结构不同。
4. D 紧凑日常（备选）：WorkBuddy 目录截图的紧凑导航关系；缩窄历史栏，去掉欢迎语，把输入区提前到第一屏。
5. E 专家优先（备选）：先选角色再描述任务；顶部三列专家条、下方输入，适合高频复用专家。
6. F 专注书写（备选）：少装饰、大正文、底部能力操作；安静单栏，用文字任务而非卡片做导航。

三完整版共用真实文案、功能边界与44px点击区域。不是简单换色：A 居中、B 左右分工、C 顶部导航项目桌面。每版均有目录、详情、示例填入、临时能力选择、模型设置和项目选择的本地交互；不模拟任务执行成功。
