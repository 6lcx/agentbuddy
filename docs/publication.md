# GitHub publication

The repository contains application source, tests, dependency lockfiles, deployment templates and project documentation.

Local `.env` files, API credentials, databases, uploaded files, generated deliverables, execution logs and installed dependencies are excluded. Screenshots referenced by historical design notes remain local. Curated screenshots in `docs/screenshots/` are captured from an isolated demonstration workspace and included for the README and release introduction; they contain no personal task history or model credentials. Public provider URLs and loopback addresses in examples are documentation or test configuration, not private service endpoints.

The initial GitHub commit is a sanitized source snapshot. Earlier local commits are deliberately not included in its ancestry. Configure credentials locally after cloning; never add a real credential or private service endpoint to an example file. The GitHub repository is private by default.
