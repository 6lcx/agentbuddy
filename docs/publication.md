# GitHub publication

The repository contains application source, tests, dependency lockfiles, deployment templates and project documentation.

Local `.env` files, API credentials, databases, uploaded files, generated deliverables, execution logs, installed dependencies and runtime screenshots are excluded. Screenshots referenced by historical design notes remain local and are not bundled in this repository. Public provider URLs and loopback addresses in examples are documentation or test configuration, not private service endpoints.

The initial GitHub commit is a sanitized source snapshot. Earlier local commits are deliberately not included in its ancestry. Configure credentials locally after cloning; never add a real credential or private service endpoint to an example file. The GitHub repository is private by default.
