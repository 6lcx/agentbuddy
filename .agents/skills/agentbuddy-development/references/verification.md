# 按变更选择验证

具体判定以当前 Spec 为准。测试可观察行为，不仅匹配函数名、文档措辞或实现结构。

| 范围 | 重点行为 |
| --- | --- |
| F1 专家 | 多对多绑定复用、解绑不删除共享能力、运行快照不受后续配置修改影响 |
| F2 Skills | 无效包报错、按需加载、脚本真实执行并产出有效文件、依赖缺失不伪装成功 |
| F3 MCP | 远程与进程型工具发现/调用、连接失败、进程退出、生命周期清理 |
| F4 执行内核 | 返回运行标识、工具结果进入后续执行、页面断开不取消、刷新可查看 |
| F5 协作 | 独立任务执行时间重叠、依赖等待、候选范围、同路径文件冲突处理 |
| F6 恢复 | 有限重试、确定性失败停止、取消阻止新派发、重启标为中断、迟到结果不复活终态 |
| F7 预算 | 共享计数、重试不重置、最后额度并发不超发、超时、用户等待暂停与过期 |
| F8 文件 | 目录与真实格式、下载内容一致、必需文件缺失不成功 |
| F9 版本 | V1 哈希不变、V2 更新要求文件、失败不替换成功快照、并发修改不覆盖 |
| F10 对话装配 | 卡片与示例只填草稿、会话覆盖不改模板、切换保留显式增减、通用助手不自动组团、必需依赖缺失先补齐 |
| 办公文件 | Word/Excel/PPT 生成和基础读取、自产文件修改、实际内容与显示验证；外部文件不假称保真编辑 |
| 外部操作确认 | 未确认不执行、拒绝不执行、确认绑定具体目标和内容、改动后重新确认、结果未知不盲重试 |
| 路由 | 非默认前缀下页面刷新、事件、文件/版本下载可用 |
| SQLite | 外部等待不持写事务、并发事件不丢关键终态、重启状态可解释 |

## 证据层次

- 逻辑测试：解析、状态、预算结算，超时优先用可控时钟。
- 竞争条件：让请求同时争用最后额度，核对实际派发数量；顺序循环无法证明并发正确。
- 集成：临时 SQLite、工作目录、可控 MCP 服务和真实脚本进程，实际读取产物；不把用户项目当可删除夹具。
- UI：按改动验证加载、提交、运行、错误、下载；截图只证明可见布局，不证明后台完成。
- 端到端：按影响选择 Spec 场景 A–F，注明是否真实模型。模拟能证明控制流程，不能证明真实模型的 Skill 选择或规划质量。

读取实际 pyproject.toml、锁文件、package.json、CI 和测试目录来确定命令；不凭本 Skill 执行尚不存在的测试命令。

相关检查通过后停止重复测试。失败先定位再修复，不扩大重试掩盖问题；外部服务不可用时完成本地部分，明确列出受阻验收，不用模拟通过替代真实集成。
