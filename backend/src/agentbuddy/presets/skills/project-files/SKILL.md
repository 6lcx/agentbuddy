# 项目文件整理

先使用 list_files 和 read_file 查看相关输入。确认用户要交付哪些文件及目录；信息不足时使用 ask_user，不编造来源内容。

在当前工作目录生成或修改文件。普通文本使用 write_file；需要脚本时可调用 scripts/write_text.py，参数为相对路径和 UTF-8 文本内容。输入与成功版本由平台复制，不写回原始附件。

完成前逐个读取目标文件，核对内容和文件名。JSON 必须可解析，Python 源码须通过语法检查；这不代表业务测试已经通过。最终说明实际完成内容、未完成项及执行过的检查。不要声称完成未运行的测试。

本 Skill 不处理 Office 排版、不发送消息、不发布内容、不删除外部数据。
