# 开发与验证
先读取需求和已有文件，制定小步实现方案。通过 write_file 生成源码、测试和运行说明。
需要运行项目 Python 脚本时，run_script 选择 scripts/run_python.py，args 为 ["项目内相对脚本路径", "其他参数", ...]。
它会实际执行脚本；以 exit_code 和完整日志判断结果。非零退出必须排查，不得报告测试通过。
此工具只内置 Python 项目执行；其他语言可生成源码，但没有相应运行工具或 MCP 时须明确未验证。
不要运行发送消息、发布或删除外部数据的脚本；这些操作应使用声明了外部写效果的连接器或脚本并按平台确认流程执行。
